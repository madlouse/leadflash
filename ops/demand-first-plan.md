# LeadFlash — Demand-first plan (next 7 days, no payment)

> Phase: **demand validation**. Goal is conversations and pilot interest — not checkout links.  
> Assets ready: `site/index.html`, `site/demo.html` (sandbox), honest mailto CTA.  
> Audience TZ: Asia/Shanghai. Owner: Jack.

**Hard rules**

- No payment links, no Stripe/Lemon, no “buy now.”
- Legal/honest copy only: sandbox ≠ live client inbox; no guaranteed lead volume or ROI.
- Demo path: fake lead → ~60s draft → human approve → send → pending book + escalation card.

---

## North-star for the week

| Metric | Target | Notes |
|--------|--------|-------|
| Conversations started | **10** | DM / email / call / Discord — real back-and-forth, not likes |
| Pilots interested | **2** | Said yes to a live 15-min walkthrough *or* “want to try on our channel after auth” |
| Demo link shared | Every outreach | Always include `demo.html` (or site `#demo` → sandbox) |

Success = talks + interest signals. Not revenue this week.

## Day-by-day (lightweight)

### Day 1–2 — Publish & pin the demo

- [ ] Ship `index.html` + `demo.html` to the public site / GitHub Pages / whatever Jack uses.
- [ ] Pin or first-line the sandbox link in bio / pinned post / email signature.
- [ ] Self-walk the sandbox once in CN and once in EN; fix any broken mailto.

### Day 3–4 — Content posts (3–5 short pieces)

Reuse / adapt `content/cold-start-posts-*.md` if present. Themes (honest):

1. **Why first 10 minutes kill local jobs** (plumber/HVAC story) → CTA: try sandbox.
2. **Sandbox walkthrough thread** — screenshots or Loom of `demo.html` (label “sandbox”).
3. **Human boundary** — price / contract / safety stay human (escalation card).
4. **What we don’t sell** — no lead-volume guarantee, no fake “booked” UI.
5. Optional EN mirror of #1 or #2 for bilingual reach.

Each post ends with: sandbox link + “Request live walkthrough → mailto”.

### Day 5–6 — Outbound conversations

- Warm list: past chats, local-service owners, communities Jack already is in.
- Script opener (CN): 发沙盒链接 → 问「你们线索主要卡在半夜回不上吗？」→ 邀 15 分钟讲解.
- Log every conversation in `experiment-log.md` (date, channel, outcome: talk / pilot-interested / no).

### Day 7 — Review

- Count: talks (≥10?), pilots interested (≥2?).
- Keep / kill message angles that got replies.
- If 2+ pilots: schedule walkthroughs; prepare onboarding checklist only — still no payment page unless Jack explicitly opens sales.
